# Fruit Shop 🍎

A fresh fruit store website — browse products and get in touch, built with HTML, CSS and JavaScript.

## 🔗 Live demo

**[fruit-shop-teal.vercel.app](https://fruit-shop-teal.vercel.app)**

## 📄 Pages

- `index.html` — Home / shop
- `contact.html` — Contact

## 🛠️ Tech

`HTML` `CSS` `JavaScript`

## ▶️ Run locally

Open `index.html` in your browser — no build step needed. Or serve it with any static server:

```bash
python -m http.server
```

Then open `http://localhost:8000`.
